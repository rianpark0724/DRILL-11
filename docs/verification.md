# AutoRun 검증 결과

검증일: 2026-10-27

## 실행 환경과 결과

- Windows, Python 3.14, 설치된 pico2d 및 transitions 사용.
- `python -m unittest -v test_autorun`: 6개 테스트 모두 통과.
- 테스트는 실제 `transitions.Machine`과 실제 키 이벤트 처리 함수를 사용한다. 이미지 로딩·캔버스 너비·시각·이벤트 공급만 대체하여 경계 조건을 재현한다.
- 실제 pico2d 캔버스를 열어 잔디, AutoRun 스프라이트, 경계 반사 후 스프라이트, 일반 RUN 스프라이트를 렌더링하고 정상 종료하는 스모크 검사 통과.
- `git diff --check` 통과.
- 상태도 SVG의 XML 파싱 통과. Mermaid 원본과 SVG에 동일한 상태 전이 10개를 표현했다.

## 산출물 및 한계

- `state-diagram.mmd`: 수정 가능한 Mermaid 상태도 원본.
- `state-diagram.svg`: 브라우저에서 열 수 있는 벡터 이미지. Node/npx가 기본 실행 환경에 없어 별도 패키지를 설치하지 않고 동일한 상태도를 SVG로 직접 작성했다. Mermaid 자동 렌더링 결과물은 아니다.
- 실제 GUI 렌더링 호출은 검증했지만 사람이 화면을 보며 크기, 애니메이션, 발 위치를 확인하거나 키보드를 직접 조작하는 육안 검증은 하지 않았다.
- 지속 시간은 실제 시계의 경과 시간으로 처리한다. 자동 테스트에서는 대기 없이 경계 시각을 정확히 검증하기 위해 시계를 대체했다.

## 수동 확인 방법

1. pico2d와 transitions가 설치된 Python으로 `main.py`를 실행한다.
2. IDLE에서 a를 누르고 확대·가속·양끝 반사를 확인한다.
3. 5초 뒤 원래 크기로 정지하고, 추가 유휴 5초 뒤 잠드는지 확인한다.
4. 다시 기상하여 a를 누른 뒤 좌우 방향키로 취소하고 정상 이동·정지를 확인한다.
5. `state-diagram.svg`를 브라우저로 열어 상태와 화살표를 확인한다.
